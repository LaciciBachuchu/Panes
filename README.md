# Panes

免费开源的 macOS 窗口管理器，合并了 BetterSnapTool 和 Moom 的功能。需要 macOS 14 或更新版本，Apple 芯片和 Intel 芯片都支持。

## 安装

1. 到 [Releases](https://github.com/LaciciBachuchu/Panes/releases/latest) 下载 `Panes.zip`，解压后把 `Panes.app` 拖进「应用程序」文件夹。
2. 第一次打开时 macOS 会提示「无法验证开发者」，因为这个 App 没有经过 Apple 公证（那需要付费开发者账号）。点「完成」，然后打开 系统设置 → 隐私与安全性，在页面下方点「仍要打开」，再确认一次。
   - 或者在终端运行：`xattr -dr com.apple.quarantine /Applications/Panes.app`，之后就能直接打开。
3. 按提示在 系统设置 → 隐私与安全性 → 辅助功能 里打开 Panes。macOS 只允许有这个权限的 App 移动其他 App 的窗口，打开后 Panes 立即开始工作。
4. 菜单栏会出现一个四宫格图标，设置都在里面。

## 功能

| 功能 | 说明 |
|---|---|
| 拖拽吸附 | 把窗口拖到屏幕边缘/角落，显示预览，松手即吸附。吸附区域可自定义（边缘可分段，比如底边默认分三段 = 三等分） |
| 拖离还原 | 拖动已吸附的窗口时自动恢复原来的大小 |
| 临时禁用 | 拖动时按住 ⌘（可改）不吸附 |
| 快捷键 | 每个动作直接按快捷键触发，不需要先进入"键盘模式"。重复按同一快捷键循环尺寸：½ → ⅔ → ⅓ |
| 绿色按钮面板 | 悬停绿色按钮时，系统菜单照常弹出，Panes 面板（预设位置 + 网格拖选）出现在它右侧，和系统菜单一起开关；鼠标进入面板后则保持到选择/点别处/Esc。点击绿色按钮本身仍是系统默认行为 |
| 悬停移动/缩放 | 按住 ⌃⌥⌘ 移动鼠标=移动窗口；⌃⌥⌘⇧=从最近的角缩放。不用点击，后台窗口也行 |
| 布局 | 保存/恢复所有窗口位置；可绑定快捷键；接上同一组显示器时自动恢复。最小化的窗口不会被弹出来 |
| 忽略的 App | 不处理这些 App 的窗口；它们在前台时快捷键自动让路（远程桌面/虚拟机/游戏） |
| 卷起 + 看一眼 | 双击标题栏或按 ⌃⌥⇧C，窗口的高度缩到只剩标题栏，留在原处（不隐藏、不最小化）；再双击恢复。指针停在卷起的窗口上约 0.2 秒，下面挂出卷起时的画面，单击展开。Panes 退出或崩溃都会把高度还回去。有些 App 规定了最小高度（如网易云音乐），这类窗口不能卷起，会提示一下 |
| 标题栏手势 | 指针在标题栏上：两指往上推卷起（卷起的窗口往下拉展开）、往下拉铺满、左右走 ½ → ⅔ → ⅓ → 换显示器，滑到底再拐弯占角，张开铺满、捏合撤销；普通鼠标滚 3 格算一次。松手才执行，旁边有小浮窗提示 |
| 甩动 | 拖着标题栏快速甩出去再松手：上 = 卷起，下 = 铺满，左右 = 半屏，斜着 = 角落；松手时在吸附区域里仍按吸附 |
| 其它 | 窗口间距、几乎最大化、最大化高度、居中、放大/缩小、移到下一个显示器、还原、设置导入导出、开机启动 |

## 默认快捷键（⌃⌥ = Control + Option）

| 快捷键 | 动作 |
|---|---|
| ⌃⌥← / → / ↑ / ↓ | 左/右/上/下半屏（重复按循环 ⅔、⅓） |
| ⌃⌥U / I / J / K | 左上/右上/左下/右下四分之一 |
| ⌃⌥D / F / G | 左/中/右三分之一 |
| ⌃⌥E / T | 左/右三分之二 |
| ⌃⌥↩ | 最大化 |
| ⌃⌥M | 几乎最大化 |
| ⌃⌥⇧↑ | 最大化高度 |
| ⌃⌥C | 居中 |
| ⌃⌥⌫ | 还原 |
| ⌃⌥= / - | 放大/缩小 |
| ⌃⌥⌘→ / ← | 移到下一个/上一个显示器 |
| ⌃⌥P | 在当前窗口上打开面板（1–9 选预设，Esc 关闭） |
| ⌃⌥⇧C | 卷起当前窗口 / 指针在卷帘条上时展开 |

卷起用 ⌃⌥⇧C，是因为 ⌃⌥⌘ 按住时是"悬停移动"。所有快捷键都能在设置里改。

卷起和手势在设置 →「窗口功能」里各有开关。"看一眼"要显示画面，需要在 系统设置 → 隐私与安全性 → 屏幕录制 里允许 Panes（Panes 第一次启动时会请求）；没有这个权限时只显示提示。

## 自己编译

需要 Xcode。

```bash
Scripts/build_app.sh --install    # 编译并安装到「应用程序」
Scripts/build_app.sh --release    # 编译通用版本并打包成 build/Panes.zip
```

脚本会自动用钥匙串里的「Panes Local Signing」代码签名证书签名，所以重新编译后辅助功能权限不会失效。没有这张证书时退回 ad-hoc 签名，每次编译后都要在辅助功能里把 Panes 删掉重加。
